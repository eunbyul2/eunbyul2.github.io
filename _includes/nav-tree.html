{%- comment -%} Recursive sidebar navigation tree, data-driven by _data/nav.yml. Supports unlimited nesting depth: a leaf has `url`, a group has `children`. Groups render expanded by default. A group may ALSO have its own `url` (e.g. "Kubernetes" itself has posts, in addition to its "Cilium" child) -- in that case the title text is a real link, and only the small caret icon toggles expand/collapse (click handler lives in sidebar.html). Params: items - array of nav nodes to render at this level parent - unique id prefix for this level (used to build collapse target ids) root - true only for the outermost call (skips the collapse-wrapper markup) {%- endcomment -%}
